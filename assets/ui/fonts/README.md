# Display font

Sora variable font, unmodified, from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/sora

Used at weight 600 by `display.tres` for screen titles only. Body text uses the existing
Godot font. The accompanying `OFL.txt` is explicitly included in Android exports.
